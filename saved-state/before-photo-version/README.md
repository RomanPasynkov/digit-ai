# Снимок данных перед выделением учебной копии

Сохранено 18 ноября 2026 года из папки запуска основного рабочего проекта:

- `train.txt` — 100 примеров;
- `test.txt` — 10 примеров;
- `memory` — три существовавших файла весов.

Это снимок фактического состояния файлов, а не утверждение о качестве обучения.
Снимок включён в Git намеренно. Обычные `bin`, `obj` и `.vs` в Git не включаются.

Чтобы восстановить это состояние, закройте программу, сохраните более новые
данные отдельно, соберите полное рабочее решение из `working-version`
и скопируйте эти два файла и папку `memory` в
`working-version/PI32_Pasynkov_DigitAI/bin/Debug`.
Для конфигурации Release путь заканчивается на `bin/Release`.

Исходники рабочей версии находятся в `working-version`.
Тег `working-network` сохраняет прежнее расположение этого проекта в корне.
