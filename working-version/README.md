# Полная рабочая версия

Открыть [PI32_Pasynkov_DigitAI.sln](PI32_Pasynkov_DigitAI.sln).

Здесь сохранён проект с дополнениями ассистента: полный цикл обучения,
тестирование с подсчётом точности, устойчивый softmax, прогресс и остановка.
Это не дословный код с фотографий занятия.

Проект перенесён сюда из корня без изменения алгоритмов и интерфейса.
Локальные выборки, веса и результаты сборки перенесены вместе с ним.
Решение в корне репозитория теперь содержит вариант по фотографиям.

После клонирования GitHub-репозитория папок `bin` нет. Соберите это решение
и при необходимости скопируйте выборки и папку весов из
`../saved-state/before-photo-version` в `PI32_Pasynkov_DigitAI/bin/Debug`
при закрытой программе. Перед заменой сохраняйте более новые данные отдельно.

Проверки запускаются из корня репозитория:

```powershell
.\tests\run-checks.ps1
```

Первоначальное состояние сохранено в теге `working-network`.
Внутри этого исторического тега полная версия ещё лежит в корне репозитория.
