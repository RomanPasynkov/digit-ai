# Распознавание цифр 3×5

Учебный проект на C#, Windows Forms, .NET Framework 4.8.

Основное решение: [PI32_Pasynkov_DigitAI.sln](PI32_Pasynkov_DigitAI.sln).
Оно содержит учебную версию по фотографиям занятия, без дополненного
ассистентом полного цикла обучения. Готовая рабочая версия сохранена
отдельно в `working-version`.

## Два отдельных решения

| Вариант | Что открывать | Назначение |
|---|---|---|
| По фотографиям — основной проект | [Основное решение](PI32_Pasynkov_DigitAI.sln) | Видимый код занятия и помеченный пропуск в скрытом обратном проходе |
| Полная рабочая версия | [Рабочее решение](working-version/PI32_Pasynkov_DigitAI.sln) | Полный цикл обучения и тестирования, добавленный ассистентом |

Исходники и папки запуска двух решений независимы. Изменения основного учебного
проекта не заменяют файлы в `working-version`. В одном решении не добавляйте второй проект:
открывайте нужный `.sln` отдельно.

В основном учебном проекте нет готового запуска полного обучения и подсчёта точности.
Кнопка «Обучить» сохранена в прежнем виде: она добавляет один пример в файл.
Кнопка «Тест» пока не подключена. Полный интерфейс обучения и тестирования
находится в решении внутри `working-version`.

Подробное происхождение кода и ограничения:
[PHOTO_VERSION.md](PHOTO_VERSION.md).

## Сохранённое рабочее состояние

Перед подготовкой отдельной версии по фотографиям сохранены:

- исходный код основного решения — в первом коммите репозитория;
- выборки и имевшиеся веса — в `saved-state/before-photo-version`;
- локальный ZIP исходников и данных — в `local-archives` (не включается в Git).

Тег `working-network` указывает на исходную сохранённую рабочую версию.
Чтобы пользоваться полной версией сейчас, откройте решение из `working-version`.
Чтобы получить отдельную папку именно из тега без изменения текущих файлов:

```powershell
git archive --format=zip --output=working-network.zip working-network
```

Архив содержит исходники и снимок данных, но не результаты сборки.
В теге `working-network` сохранена прежняя структура: рабочий проект лежит в корне.
В текущей ветке он перенесён в `working-version`, а основным стал проект по фотографиям.

После сборки решения из `working-version` можно скопировать `train.txt`, `test.txt`
и папку `memory` из `saved-state/before-photo-version` в
`working-version/PI32_Pasynkov_DigitAI/bin/Debug` при закрытой программе.
Это восстановит сохранённые данные; сначала сохраните свои более новые файлы,
если уже продолжали обучение или дополняли выборки.

## Данные

Одна строка выборки: правильная цифра от 0 до 9 и 15 пикселей, разделённых пробелами.
Пиксели идут по строкам рисунка 3×5, слева направо, сверху вниз. Чёрный — 1, белый — 0.

Фотография листка и её расшифровка находятся в `digit_sheet`:
`source_photo_2026-11-17.png`, `photo_samples_2026-11-17.json`,
`photo_samples_check.png`. Первые 10 примеров каждой цифры относятся к обучению,
последний — к тестированию. В листке есть конфликт: третий рисунок восьмёрки
совпадает со вторым рисунком нуля; он сохранён без исправления.

## Проверки рабочей версии

```powershell
.\tests\run-checks.ps1
```

Проверки используют временные данные и не обучают сеть на пользовательских файлах.
Нужны Windows, Visual Studio 2022 Community и комплект разработки .NET Framework 4.8.
Результаты сборки, локальные настройки Visual Studio и старые резервные копии
не включаются в Git. Репозиторий: https://github.com/RomanPasynkov/digit-ai.

Проверка основного учебного проекта:

```powershell
.\tests\run-photo-checks.ps1
```

Она проверяет чтение выборок, прямой проход, видимую реализацию выходного
обратного прохода и явное сообщение о недостающем фрагменте скрытого слоя.
Этот тест не объявляет скрытый обратный проход реализованным.

После добавления адреса GitHub отправьте ветку `main` и теги,
чтобы метки сохранённых версий также попали на сервер.
